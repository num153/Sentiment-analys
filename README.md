# Sentiment-analysis
Xây dựng quy trình xử lý ngôn ngữ tự nhiên (NLP) nhằm phân tích và phân loại sắc thái cảm xúc từ tập dữ liệu bình luận khách hàng trên sàn thương mại điện tử. Thực hiện tiền xử lý văn bản tiếng Việt, trích xuất đặc trưng (TF-IDF) và tối ưu hóa mô hình học máy (Logistic Regression). Đánh giá hiệu năng mô hình đạt độ chính xác tổng thể Accuracy 86% và F1-Score trung bình 86%
